# Github图片预览增强

一个强大的用户脚本，为GitHub提供增强的图片预览功能，让浏览图片更加便捷和舒适。

## 功能特性

| 功能 | 描述 |
|------|------|
| 🖱️ 单击预览 | 单击图片即可丝滑预览，完整自适应显示图片 |
| 🔍 缩放功能 | 支持滚轮缩放，可放大或缩小图片 |
| 🖱️ 拖拽移动 | 可拖拽移动图片，查看大图的任意部分 |
| ⌨️ 左右切换 | 在页面中的图片组之间使用按钮或键盘左右键切换 |
| 💾 下载功能 | 可下载预览的图片 |
| ⏭️ 双击跳转 | 双击图片跳转到原图页面 |
| ✨ 丝滑动画 | 流畅的过渡动画，提升用户体验 |
| 📱 响应式设计 | 支持移动端设备 |
| 🔄 自动绑定 | 动态加载的图片也能自动启用预览功能 |

## 安装方法

1. 安装用户脚本管理器（如 Tampermonkey 或 Greasemonkey）
2. [安装脚本](https://github.com/Re0XIAOPA/Github-Image-Preview-Plus/raw/main/JavaScript/gipuls.js)

## 使用方法

| 操作 | 功能 |
|------|------|
| 单击图片 | 打开预览模式，图片会自适应显示在屏幕中央 |
| 滚轮滚动 | 放大或缩小图片 |
| 拖拽图片 | 移动图片位置 |
| 双击图片 | 跳转到原图页面 |
| 点击左右箭头 | 切换到相邻的图片 |
| 点击下载按钮 | 下载当前图片 |
| 按ESC键 | 关闭预览 |
| 按左右方向键 | 切换图片 |
